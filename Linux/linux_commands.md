# Linux Command Reference



This document records the basic Linux commands used during the CSE103 project.



| Command | Purpose |

|---|---|

| `whoami` | Displays the current username |

| `pwd` | Displays the current working directory |

| `uname -a` | Displays kernel and system information |

| `ls` | Lists files and directories |

| `ls -la` | Lists all files, including hidden files |

| `cd` | Changes the current directory |

| `mkdir` | Creates a directory |

| `touch` | Creates an empty file |

| `cat` | Displays file contents |

| `cp` | Copies files |

| `mv` | Moves or renames files |

| `rm` | Removes files |

| `chmod` | Changes file permissions |

| `ps` | Displays running processes |

| `df -h` | Displays disk space information |

| `free -h` | Displays memory information |

| `man` | Opens a command's manual |



## Practical Environment



- Linux distribution: Ubuntu 26.04.1 LTS

- Environment: WSL2

- Terminal: Ubuntu Bash



## Learning Outcome



I learned how to navigate the Linux terminal, inspect system information, manage files and directories, and understand basic Linux administration commands.
